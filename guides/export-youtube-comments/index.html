How to Export YouTube Comments to Excel or CSV (No API Key)

Export all comments and replies from any YouTube video or Short to Excel, CSV or JSON. No YouTube API key or coding needed. Includes likes, reply counts and video stats.

By the Scraplex team at ITclan BDUpdated 19 Nov 20266 min read
Short answerPaste up to 20 YouTube video or Shorts links into the YouTube Comments Scraper on Apify, choose Newest or Top, decide whether to include replies, and run it. You get every comment with its text, likes, reply count, author and the video's own stats, exportable to Excel or CSV. No API key is needed and it starts at $0.50 per 1,000 comments.

YouTube comments are unfiltered customer research. Viewers ask questions, compare products and say what they want next. Reading them on the page works for one video. For ten videos, or a competitor's whole channel, you need an export.

Why export YouTube comments

Marketers use comment exports to find content ideas, brands use them to track how a launch lands, and agencies use them to check that an influencer's audience is real. In a spreadsheet, you can sort by likes, filter by keyword and count recurring questions in minutes.

The problem with the YouTube API

The official YouTube Data API can return comments, but you need a Google Cloud project, an API key and code to page through results, and daily quota limits cap how much you can pull. The YouTube Comments Scraper skips all of that: you paste links and get a file.

How to export comments in 4 steps

  1. Copy the links of the videos or Shorts you want. Full links, Shorts links and youtu.be links all work.
  2. Open the YouTube Comments Scraper on Apify and paste up to 20 links into video_urls.
  3. Pick sort_type: Newest for monitoring, Top for the most liked comments. Set max_comments, or turn on scrape_all_comments to get everything.
  4. Press Start, then download the results as Excel, CSV or JSON.
{
  "video_urls": ["https://www.youtube.com/watch?v=..."],
  "sort_type": "Top",
  "includeReplies": true,
  "max_comments": 1000
}

Data you get for each comment

GroupFields
Commenttext, likes, publish time, reply count, reply level, isReply
Commentername, channel ID and URL, avatar, verified flag, creator flag
Videotitle, description, keywords, category, duration, publish date, views, likes
Channelchannel name, ID and URL

The creator flag marks replies from the channel owner, which is useful for checking how actively a creator talks to their audience.

5 ways to use comment data

  1. Content ideas: filter for comments containing "how" or "can you" to list the questions your audience asks.
  2. Product feedback: export comments from review videos of your product and your competitors'.
  3. Launch tracking: run the export daily for the first week after a launch video.
  4. Influencer vetting: look for repeated, generic comments that suggest bought engagement.
  5. Sentiment analysis: send the text column to an AI model and score each comment.

FAQ

How much does it cost?

From $0.50 per 1,000 comments. Exporting 10,000 comments costs about $5.

Does it include replies?

Yes, by default. Set includeReplies to false to collect top-level comments only.

How many videos can I run at once?

Up to 20 links per run. For a whole channel, split the links across several runs or schedule them.
