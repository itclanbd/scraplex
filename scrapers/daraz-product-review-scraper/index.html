For developers

Run it from your code

Python with the official Apify client. JavaScript and cURL work the same way.

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run = client.actor("itclan-bd/daraz-product-review-scraper").call(run_input={
    "urls": ["https://www.daraz.com.bd/products/..."],
    "country": "BD",
    "sorting_order": 1,
})

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Questions

Questions about this scraper

Can I get only negative reviews?

Yes. Set star_filter to 1 or 2 to collect only those ratings.

Are reviewer names shown in full?

Daraz masks most reviewer names on its own site, and the scraper returns them as Daraz shows them.

How do I run a scraper?

Open the scraper on Apify, create a free Apify account, fill in the input and press Start. Results export to CSV, JSON, Excel or Google Sheets, or come back through the Apify API.

How is pricing worked out?

You pay per result on Apify, at the price shown on each scraper. Apify bills you directly. Custom feeds are quoted per project.
